Nightshade — Shadow Courier: a complete, original top-down stealth game that runs offline in a desktop browser from static files. Three levels (The Rooftop Archive, The Lantern Courtyard, The Vault of Echoes) with patrolling lantern guards, wall-clipped vision cones, bushes and crates to hide behind, scrolls to steal, a locked exit door that opens only when every scroll is gathered, suspicion / chase / search guard AI, noise that draws guards when you run, sneak mode (Shift), click-to-move, lives, score with time and ghost-run bonuses, synthesized WebAudio sounds (no audio files), and full keyboard + mouse play. No network requests, no libraries, no build step.

## Run it

```sh
node serve.ts
```

Then open http://localhost:8080 in desktop Chrome and play. Or open `game/index.html` from any static server.
